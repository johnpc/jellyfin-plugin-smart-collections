Smart Collections

Help
For each collection, you can specify multiple tags separated by commas (e.g., "christmas, holiday, winter"). Choose "OR" to include items matching any tag, or "AND" to require items match all tags.
Use the "+" button to add a filter line that narrows the collection down. Put the subject on the first line and the narrower type on the filter line: items must match both, and commas on either line mean OR. For example "music, band" filtered by "documentary" gives music documentaries, and "sports, hockey, football" filtered by "documentary" gives sports documentaries.
